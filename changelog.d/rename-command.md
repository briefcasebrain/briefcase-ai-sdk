### Breaking
- The command is `briefcase-ai` (was `briefcase`) and the MCP server command is `briefcase-ai-mcp` (was `briefcase-mcp`), so `uvx briefcase-ai` and `pipx run briefcase-ai` work. The Python import name `briefcase` and the `BRIEFCASE_*` variables are unchanged and there is no alias for the old names. If you upgrade from 4.4: (1) use `briefcase-ai` in scripts, CI and shell aliases; (2) if you registered the MCP server with a client by hand (4.4 documented running `briefcase-mcp`, or `python -m briefcase.mcp`, which keeps working), change the registered command to `briefcase-ai-mcp` yourself, keeping the scope and environment you registered it with, for example in Claude Code `claude mcp remove --scope <scope> briefcase` then `claude mcp add --scope <scope> briefcase -- briefcase-ai-mcp`; `briefcase-ai connect` never replaces a registration it did not make, and tells you the two commands instead; (3) `briefcase stack` is gone: see the separate `briefcase-ai stack` entry.
