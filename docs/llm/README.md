# LLM context & editor rules

Drop-in context so AI coding tools generate correct briefcase-ai code in *your*
project. Pick the file that matches your tool and copy it into your repo:

| Tool | Copy this file → to |
| --- | --- |
| Cursor | `cursor-rules.mdc` → `.cursor/rules/briefcase.mdc` |
| Claude Code | `claude.md` → append to your project's `CLAUDE.md` |
| Codex / generic agents | `agents.md` → append to your project's `AGENTS.md` |

All three encode the same short rules. For the full recipe book see
[`../../llms-full.txt`](../../llms-full.txt); for a machine index see
[`../../llms.txt`](../../llms.txt). A condensed recipe list is in
[`usage.md`](usage.md).
