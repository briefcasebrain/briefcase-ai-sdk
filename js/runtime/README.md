# @briefcase-ai/runtime

Node runtime primitives for governed AI applications. The package has no root
export; import only the capability you use:

```ts
import { HashChainAppender } from "@briefcase-ai/runtime/integrity";
import { createLakefsClient } from "@briefcase-ai/runtime/lakefs";
import { runConnectorSync } from "@briefcase-ai/runtime/connectors";
import { createTraceRecorder } from "@briefcase-ai/runtime/trace";
```

The runtime owns mechanisms and contracts. Applications retain provider
implementations, credentials, authentication and authorization policy,
databases, and domain-specific resource mapping.

## Subpaths

- `integrity`: canonical JSON, SHA-256 hash chains, CAS stores, and verification.
- `lakefs`: typed lakeFS REST client with bounded read retries and request deadlines.
- `connectors`: refresh-safe sync orchestration, PKCE state, and AES-GCM envelopes.
- `trace`: ordered invocation and step recording behind a `TraceStore` port.

## Cross-language hashes

`canonicalJson` and Python's `briefcase.integrity.canonical_json` produce
byte-identical output, and so identical SHA-256 hashes, for exactly these
values:

- `null`, booleans, and well-formed Unicode strings;
- integers: a JS `number` within the safe range (|n| <= 2^53 - 1) or a
  `bigint` of any size, against a Python `int`;
- arrays and plain objects of those, with any string keys (keys sort by
  Unicode code point on both sides);
- in `computePayloadHash` only, a `Date` against a timezone-aware UTC Python
  `datetime` (both hash as `2026-01-01 00:00:01.001000+00:00`).

`tests/vectors/canonical_json.json` pins this subset with golden vectors
generated by the Python implementation; both languages are tested against it.

They do **not** agree on floats (`1.0` and `1e16` are `1.0` and `1e+16` in
Python but `1` and `10000000000000000` here), on JS `number` integers beyond
the safe range, or on naive or non-UTC Python datetimes. Encode decimals as
strings and large integers as `bigint`. Neither side implements RFC 8785.

Values that JSON cannot represent (`undefined`, `Map`, `Set`, typed arrays,
functions, non-finite numbers, lone surrogates, and `Date` outside
`computePayloadHash`) throw a `TypeError` instead of being hashed as `{}`.
The trace recorder converts such values to plain JSON before hashing (a
`Date` becomes its ISO string) and reports them as `payload_sanitized`.

`verifyChainSegment` checks prior-hash linkage and entry hashes, and payload
hashes when you pass the row payloads. Entry signatures are written only by
the Python appender and are not verified here.

## Behavior notes

- `lakefs`: the endpoint must be `https:` because credentials use Basic auth;
  plain `http:` needs a loopback host or `allowInsecure: true`. Failed
  requests throw `LakefsError` with `status` and `body`.
- `connectors`: `fetchResources` may return an async iterable of pages; each
  page reaches the sink before the next is fetched.
- `trace`: at most `maxPendingWrites` (default 10 000) writes queue behind the
  store; beyond that, new starts are dropped and reported, never thrown.
